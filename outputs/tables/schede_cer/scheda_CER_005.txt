SCHEDA CER - 5 FAMIGLIE (Lombardia, pesi AVQ originali)
======================================================================

Fonte: ISTAT Aspetti della vita quotidiana 2024 (microdati, Lombardia, 1.831
famiglie) + Censimento permanente della popolazione 2021 (rilascio 2023).
Allocazione gerarchica a resto maggiore: prima le classi di dimensione, poi le
tipologie occupazionali entro ciascuna (tipologie_famiglie.py --famiglie 5).

Composizione per dimensione x tipo occupazionale:
  dim.  nessun occ.   pensionati    un adulto casa  tutti occ.  totale  
  1     0             1             0               1           2       
  2     0             1             0               0           1       
  3     0             0             1               0           1       
  4     0             0             1               0           1       
  5+    0             0             0               0           0       
                                                                --------
  totale                                            5       

Raffrescamento assunto: 5/5 famiglie (100% contro il 55,6% ISTAT, Dotazioni energetiche 2024,
Tavola 3 - a N=5 l'arrotondamento cella per cella puo' spingere la quota molto sopra
o sotto il 55,6% atteso: e' un artefatto della scala piccola, non un dato,
e va corretto a mano se conta per l'uso che ne fai.

ASSUNZIONE DICHIARATA: a questa taglia non tutte le combinazioni dimensione x tipo
della popolazione sono rappresentate (es. niente famiglie numerose se N e' piccolo): e'
l'effetto atteso dell'allocazione a resto maggiore su un campione piccolo, non una
scelta arbitraria - la tabella sopra mostra esattamente quali celle sono vuote.
