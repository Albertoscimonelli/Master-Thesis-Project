# Derivata da CER_configuration/CER_7_8_0.txt: stessi N=15, C=7, P=8
# (penetrazione prosumer invariata). Ogni ND e ogni PA e' un prosumer con il proprio
# impianto; per ognuno che entra esce un prosumer domestico, con il suo impianto:
#   rimossi: household_10_kWh (PV09), household_12_kWh (PV07), household_14_kWh (PV10)
# Quota non domestici: 3/15 = 20.0% (regola: sotto il 50%).
# Le righe domestiche restano quelle della scheda di partenza (stessi reddito/gas).
# ASSUNZIONI ND (da confermare):
#  - antigelo, office_zummo: consumi orari REALI 2024 (CER_LoadProfiles/outputs/Valencia/),
#    riportati sul 2025 mantenendo il giorno della settimana; FV simulato in PVsyst su
#    Milano (Duomo) dall'autore; small_industry: profilo RAMP (csv_scheda9);
#  - kWp STIMATI (produzione/1480 kWh/kWp): antigelo 33, zummo 129, small_industry 69
#    (coerenti con la taglia media PMI al Nord, 107 kW: Koltunov et al. 2026, Fig. 7);
#  - costo impianto 730 EUR/kWp (come le PA), P_prel_kW dal picco del profilo per i dati
#    reali, da CER_input.txt per i RAMP; tariffa BIORARIA per i terziari, ORARIO_VARIABILE
#    per gli industriali; categoria industriale/terziario: NON esenti dal fattore F;
#  - le PA sono quelle di CER_configuration_PA/ (stesse assunzioni).

# CER_configuration_IND/genera_varianti_IND.py.

# BOZZA di scheda CER - PIANIFICAZIONE, nessun profilo ancora generato
#
# Composizione domestica derivata da ISTAT AVQ 2024 (microdati Lombardia,
# 1.831 famiglie) + Censimento permanente della popolazione 2021 (rilascio
# 2023), allocazione a resto maggiore su 15 famiglie
# (tipologie_famiglie.py --famiglie 15).
#
# MEMBRO 'office' RIMOSSO: la CER e' ora puramente domestica. Il
# membro terziario (PV04, 17.5 kWp) e la sua colonna office_1_kWh nel
# CSV di profili_carico vanno tolti insieme - allineamento a cura
# dell'utente sul file xlsx/csv: load_cer_input.m/align_members_to_users.m
# rifiutano altrimenti la scheda (colonna del CSV senza riga in [MEMBRI]).
#
# PV01 (small_industry) OMESSO: quella scheda non ha un membro
# small_industry, quindi la riga sarebbe stata un riferimento a vuoto.
#
# PENETRAZIONE PROSUMER: 8/15 membri (53.3%),
# target ~50%. Scheda duplicata da CER_11_4_0.txt (~25%, 4/15
# membri): aggiunte 4 famiglie prosumer per portare la quota a
# ~50%, scelte con lo stesso criterio della versione ~25% (centro del
# gap piu' largo rimasto fra gli indici gia' assegnati, per non
# toccare le famiglie gia' prosumer). Indici finali (nella lista
# delle sole famiglie), non a caso: [2, 4, 5, 6, 8, 10, 12, 14].
# Ciascuna: impianto dimensionato sull'archetipo domestico (n_comp) del
# titolare, dai profili reali PROVA_CER_1_Project_*_componenti.CSV:
# 1-2 componenti = 3.4 kWp, 3-4 componenti = 4.2 kWp, 5+ componenti =
# 5.9 kWp.
#
# COSTI (capex_EUR in [IMPIANTI], quota_inv_EUR in [MEMBRI]): stima da
# tariffario di mercato indicato dall'utente (impianti senza accumulo),
# EUR/kW al punto medio della fascia dichiarata per categoria, kWp
# fisso per archetipo come sopra:
#   1-2 comp. (2-3 kW, ~1900-2200 EUR/kW): 3.4 kWp x 2050 EUR/kW ~= 7000 EUR
#   3-4 comp. (3-4,5 kW, ~1600-1900 EUR/kW): 4.2 kWp x 1750 EUR/kW ~= 7400 EUR
#   5+ comp.  (4,5-6 kW, ~1400-1700 EUR/kW): 5.9 kWp x 1550 EUR/kW ~= 9100 EUR
# Il titolare finanzia per intero il proprio impianto, quindi
# quota_inv_EUR = capex_EUR dell'impianto posseduto. Valori arrotondati
# a 100 EUR: indicativi da fascia di mercato, non un preventivo.
#
# ATTENZIONE MODELLO: load_cer_data.m legge ogni file_produzione come
# export PVsyst ASSOLUTO (kWh orari), non normalizzato per kWp. Piu'
# famiglie nello stesso archetipo (1-2, 3-4 o 5+ componenti) condividono
# lo stesso file_produzione e ne sommano quindi N volte la stessa curva:
# e' corretto SOLO se si intende N impianti realmente identici (stessa
# taglia, stesso orientamento) per archetipo - qui e' cosi' per
# costruzione (kWp fisso per fascia di componenti).
#
# NON e' ancora caricabile. DA COMPILARE A MANO PRIMA DI ATTIVARLA:
#
#   [FILE]      profili_carico: percorso del CSV con questi membri,
#               nell'ORDINE elencato qui sotto
#   [CER]       nome, comune, provincia, zona_mercato (nord|centro|sud)
#   [IMPIANTI]  tilt, azimut, opex_EUR_anno per ogni impianto (capex_EUR
#               e quota_inv_EUR sono compilati: stima di mercato, vedi sopra)
#
# PER ATTIVARLA: rinominare in CER_<C>_<P>_<E>.txt (consumatori, prosumer,
#                produttori puri), stessa cartella. MAIN.m carica i soli
#                file che iniziano per 'CER_', quindi finche' si chiama
#                'bozza_' questa scheda viene ignorata e non puo' rompere
#                nulla.
#
# Le sezioni [MERCATO], [INVESTIMENTO] e [POVERTA_ENERGETICA] non stanno
