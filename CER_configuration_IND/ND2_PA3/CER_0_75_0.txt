# (penetrazione prosumer invariata). Ogni ND e ogni PA e' un prosumer con il proprio
# impianto; per ognuno che entra esce un prosumer domestico, con il suo impianto:

#    riportati sul 2025 mantenendo il giorno della settimana; FV simulato in PVsyst su
#    Milano (Duomo) dall'autore; small_industry: profilo RAMP (csv_scheda9);
#  - kWp STIMATI (produzione/1480 kWh/kWp): antigelo 33, zummo 129, small_industry 69
#    (coerenti con la taglia media PMI al Nord, 107 kW: Koltunov et al. 2026, Fig. 7);
#  - costo impianto 730 EUR/kWp (come le PA), P_prel_kW dal picco del profilo per i dati

# Ciascuna: impianto dimensionato sull'archetipo domestico (n_comp) del
# titolare, dai profili reali PROVA_CER_1_Project_*_componenti.CSV:
# 1-2 componenti = 3.4 kWp, 3-4 componenti = 4.2 kWp, 5+ componenti =
# 5.9 kWp.
#
# COSTI (capex_EUR in [IMPIANTI], quota_inv_EUR in [MEMBRI]): stima da
# tariffario di mercato indicato dall'utente (impianti senza accumulo),
# EUR/kW al punto medio della fascia dichiarata per categoria, kWp
# fisso per archetipo come sopra:
#   1-2 comp. (2-3 kW, ~1900-2200 EUR/kW): 3.4 kWp x 2050 EUR/kW ~= 7000 EUR
#   3-4 comp. (3-4,5 kW, ~1600-1900 EUR/kW): 4.2 kWp x 1750 EUR/kW ~= 7400 EUR
#   5+ comp.  (4,5-6 kW, ~1400-1700 EUR/kW): 5.9 kWp x 1550 EUR/kW ~= 9100 EUR
# Il titolare finanzia per intero il proprio impianto, quindi
# quota_inv_EUR = capex_EUR dell'impianto posseduto. Valori arrotondati
# a 100 EUR: indicativi da fascia di mercato, non un preventivo.
#
# ATTENZIONE MODELLO: load_cer_data.m legge ogni file_produzione come
# export PVsyst ASSOLUTO (kWh orari), non normalizzato per kWp. Piu'
# famiglie nello stesso archetipo (1-2, 3-4 o 5+ componenti) condividono
# lo stesso file_produzione e ne sommano quindi N volte la stessa curva:
# e' corretto SOLO se si intende N impianti realmente identici (stessa
# taglia, stesso orientamento) per archetipo - qui e' cosi' per
# costruzione (kWp fisso per fascia di componenti).
#
# NON e' ancora caricabile. DA COMPILARE A MANO PRIMA DI ATTIVARLA:

#   [FILE]      profili_carico: percorso del CSV con questi membri,
#               nell'ORDINE elencato qui sotto
